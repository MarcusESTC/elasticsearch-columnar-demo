Columnar Logs · full-text search — still first class

Columnar Logs keeps one inverted index — on message — so operators still get instant full‑text search over the same columnar data. This queries the columnar index directly.

How the three modes differ

Standard

Every field is stored several ways at once — inverted index, doc values, stored fields — so any query pattern is fast. Great default; heaviest footprint.

SETTING index.mode: standard

LogsDB

Log-optimized: index sorting, synthetic _source, ZSTD + delta encoding. Up to 65% smaller than standard. GA since 8.17, default for serverless logs.

SETTING index.mode: logsdb

Columnar Logs

Fields stored once, as columns — no inverted index except on message. Column scans for analytics, full‑text where it matters. GA in 9.6.

SETTING index.mode: logsdb_columnar
